   194→## 1.4 Doctor Search
   195→
   196→### Controller: `Search.php`
   197→- **Class**: `Search extends Guest_controller`
   198→- **Models**: `Doctors_model` (doctor), `Hospital_model` (hospital), `City_model` (city), `Doctor_type_model` (type)
   199→- **Method**: `index()` — GET
   200→  - Params: `q` (query string, required — redirects to home if missing), `city`, `type`
   201→  - Queries:
   202→    - `$this->doctor->get_search_users($q, $city, $type)` — searches doctors
   203→    - `$this->hospital->get_search_hospital($q, $city)` — searches hospitals
   204→    - `$this->city->get_all_city()` — all cities for filter dropdown
   205→    - `$this->type->get_all()` — all doctor types for filter dropdown
   206→  - Data: `$doctors`, `$hospitals`, `$city`, `$type`, `_title={q} - Search`
   207→  - View: `front/doctor/search`
   208→
   209→### Model: `Doctors_model`
   210→- `get_search_users($keyword, $city, $doctor_type)`: Searches `users.name`, `doctors.state`, `doctors.specialization`, `doctors.eduction`, `doctors.experience` with LIKE `%keyword%`. Optional filters: city, doctor_type. Only active doctors with `hospital_id IS NULL`.
   211→  - Returns: array of matching doctors
   212→
   213→### Model: `Hospital_model`
   214→- `get_search_hospital($keyword, $city)`: Searches `hospital.hospital_name`, `hospital.state` with LIKE. Optional city filter. Only active hospitals.
   215→  - Returns: array of matching hospitals
   216→
   217→### View: `front/doctor/search.php`
   218→- Page title: "Search Results for: {q}"
   219→- **Filter form** (GET, inline):
   220→  - Hidden input: `name="q" value={q}`
   221→  - City dropdown: `name="city"` — all cities from DB with state_name suffix
   222→  - Doctor type dropdown: `name="type"` — all types from DB
   223→  - Filter button with icon
   224→- **Results**: Two sections — Doctors and Hospitals (same card layouts as listing pages)
   225→- Empty state: "Oops! did not match any result."
   226→
   227→### Connections
   228→- Tables: `users`, `doctors`, `hospital`, `city` (assumed), `doctor_type` (assumed)

   330→## 1.8 Appointment Booking
   331→
   332→### Controller: `Book.php`
   333→- **Class**: `Book extends Patient_contoller` (requires login, role=PATIENT)
   334→- **Models loaded**: Booking_model, Doctors_model, Doctor_holiday_schedule_model, Hospital_model, State_model, City_model, Config_model, Doctor_rating_model, Notifications_model, Receptionist_model
   335→
   336→- **Method**: `doctor($id)` — GET
   337→  - Validates doctor exists (active)
   338→  - Gets: doctor_total_rate_user, doctor_average_rating, all states, hospital info
   339→  - Gets holiday dates: `$this->holiday_schedule->get_next_holidays($doctor->user_id)` → JSON array for datepicker
   340→  - Data: `$doctor_total_rate_user`, `$doctor_average_rating`, `$state`, `$hospital`, `$doctor`, `$getHolidays`
   341→  - View: `front/doctor/book`
   342→
   343→- **Method**: `doctor_book($id)` — POST
   344→  - Validates doctor exists
   345→  - Runs form validation rule: `booking_by_patient`
   346→  - Checks daily limit: `$doctor->daily_limit` vs `$this->book->get_booking_count_by_date_by_doctor($id, $data['booking_date'])`
   347→    - If limit reached: `_alertSuccessResponce(1, "limit over message", "not created", "book/doctor/$id")`
   348→  - Creates booking with:
   349→    - `doctor_id` = $id
   350→    - `user_id` = current user
   351→    - `status` = PENDING
   352→    - `appointment_charge` = from config (`config_model->get_one()->admin_charge`)
   353→    - `booking_type` = BY_SELF
   354→    - `appointment_no` = auto-generated (APMT-{increment})
   355→  - Sends notification to doctor + receptionist (if exists)
   356→  - Sends SMS to patient: `sendMobileMessage(mobile_no, message)`
   357→  - On success: redirect to `appointment`
   358→  - On validation fail: re-loads book form with errors
   359→
   360→- **Method**: `generateBookingNumber()` — Internal
   361→  - Gets latest booking record, increments APMT-{N}
   362→  - If no records: APMT-1
   363→
   364→- **Method**: `city_by_state()` — POST (AJAX)
   365→  - Params: `state_name`
   366→  - Returns: JSON array of cities for given state
   367→
   368→- **Method**: `date_booked()` — POST (AJAX)
   369→  - Params: `doctor`, `date`
   370→  - Returns: `json_encode(["booked" => count])`
   371→
   372→### View: `front/doctor/book.php`
   373→- **Custom CSS**: `.disabled-date.day` — red background
   374→- **Flash message**: Shows `$this->session->flashdata('feedback')` if exists
   375→- **2-column** (col-lg-4 sidebar + col-lg-8 form)
   376→- **Left sidebar**:
   377→  - Doctor card: avatar, name, type, rating, hospital map, hospital name/address, fees, time, email, phone, description
   378→- **Booking Form** (`form_open("book/doctor_book/{doctor.user_id})`):
   379→  - **Form Fields**:
   380→    | Field | Type | Name | Validation | Notes |
   381→    |-------|------|------|------------|-------|
   382→    | Patient Name | text | `petient_name` | required | |
   383→    | Appointment Date | text (datepicker) | `booking_date` | required | `onkeydown="return false"`, autocomplete off |
   384→    | Physical Handicap | select | `physical_handicape` | optional | No/Yes |
   385→    | Symptoms | text | `disease` | optional | |
   386→    | State | select | `state` | optional | Populated from `$state` array |
   387→    | City | select | `city` | optional | AJAX populated on state change |
   388→    | Gender | select | `gender` | optional | Male/Female/Other |
   389→    | Blood Group | select | `blood_group` | optional | O+/-, A+/-, B+/-, AB+/- |
   390→    | Date Of Birth | date | `date_of_birth` | optional | readonly, triggers age calculation |
   391→    | Age | text | `age` | optional | Auto-calculated from DOB |
   392→    | Height (cm) | text | `height` | optional | |
   393→    | Weight (KG) | text | `weight` | optional | |
   394→    | Relation With Me | text | `relation_with_me` | optional | |
   395→    | Description | textarea | `description` | optional | 5 rows |
   396→  - **Submit**: "Appoint" button, disables after click (`onclick="this.form.submit();this.disabled=true;"`)
   397→- **JavaScript** (require.js):
   398→  1. **State → City AJAX**: `$.post('book/city_by_state', {state_name}, ...)` → populates city dropdown
   399→  2. **DOB → Age**: Calculates age in years from date_of_birth
   400→  3. **Datepicker**: Bootstrap datepicker on `#booking_date`
   401→     - Format: `yyyy-mm-dd`
   402→     - Disabled dates: holiday dates from PHP (red)
   403→     - Start date: today
   404→     - End date: today + `doctor.booking_days`
   405→     - On date change: checks `book/date_booked` → if daily limit reached, disables that date dynamically
   406→

   409→- External: SMS gateway (via `sendMobileMessage`)

   822→## KEY MIGRATION NOTES
   823→
   824→1. **Password hashing**: SHA256 (not bcrypt) — `hash("sha256", $password)`
   825→2. **Image uploads**: Stored in `upload/profile/`, `upload/blog/`, `upload/slider/`, `upload/gallery/`, `upload/schedule_docs/`
   826→3. **SEO URLs**: Blog posts use `paramalink` field (auto-generated from title, uniqueness enforced)
   827→4. **Rating system**: Pure CSS stars (5-point), AJAX post to `api/rate_us`, stored in `doctor_rating` table
   828→5. **Chat system**: Per-appointment, between patient and receptionist (NOT doctor), polling every 5 seconds
   829→6. **Notifications**: Created on booking/cancel, stored per user, mark-as-read on viewing notification page
   830→7. **SMS**: Sent on booking confirmation via `sendMobileMessage()`
   831→8. **Appointment number**: Auto-incrementing format `APMT-{N}`
   832→9. **Daily limit**: Doctor has `daily_limit` and `booking_days` fields that constrain booking
   833→10. **Holiday blocking**: Dates from `doctor_holiday_schedule` are disabled in datepicker
   834→11. **DataTables**: Used on appointment list (`.dttable` class), post list
   835→12. **CKEditor**: Used for blog post content (wysiwyg)
   836→13. **SweetAlert**: Used for delete/cancel confirmations
   837→14. **Disqus**: Comments on blog detail pages (hardcoded shortname)
   838→15. **AddToAny**: Social sharing on blog detail pages
   839→16. **Google Analytics**: UA-171698773-1
   840→17. **Search**: Searches across doctor name, state, specialization, education, experience AND hospital name, state
   841→18. **Pagination**: CI Pagination library, Bootstrap 4 styled, 12 per page (doctors/hospitals), 9 per page (blog)
   842→
