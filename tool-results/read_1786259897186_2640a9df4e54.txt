    84→    84→    84→### Problem Statement
    85→    85→    85→User reported "web is not working again" — preview panel showing broken/blank page.

    87→    87→    87→### Root Cause Analysis (Architect Diagnosis)
    88→    88→    88→
    89→    89→    89→#### Issue #1 — CRITICAL: Import Bug (PublicLayout Export Mismatch) 🔴
    90→    90→    90→- **Symptom**: All public pages except homepage returned HTTP 500
    91→    91→    91→- **Pages affected**: `/doctors`, `/hospitals`, `/blog`, `/blog/[permalink]`, `/about`, `/contact`, `/doctors/[id]`
    92→    92→    92→- **Root cause**: `PublicLayout` is exported as a **named export** (`export function PublicLayout`) but 7 pages imported it as a **default export** (`import PublicLayout from`)
    93→    93→    93→- **Error message**: `Export default doesn't exist in target module`
    94→    94→    94→- **Fix**: Changed all 7 files from `import PublicLayout from` → `import { PublicLayout } from`
    95→    95→    95→- **Why homepage worked**: `page.tsx` imports it correctly as `{ PublicLayout }`
    96→    96→    96→
    97→    97→    97→#### Issue #2 — Dev Server Not Running 🔴
    98→    98→    98→- **Symptom**: Connection refused / blank page in preview
    99→    99→    99→- **Root cause**: Dev server process (port 3000) was not running — previous session's processes died when context reset
   100→   100→   100→- **Fix**: Server restarted with `npx next dev --port 3000`
   101→   101→   101→- **Note**: Background processes from bash tool get killed when tool session ends; server must be restarted each session
   102→   102→   102→
   103→   103→   103→#### Issue #3 — Cross-Origin Resource Blocking 🟡
   104→   104→   104→- **Symptom**: `⚠ Blocked cross-origin request from 127.0.0.1 to /_next/* resource`
   105→   105→   105→- **Root cause**: `next.config.ts` `allowedDevOrigins` was missing `127.0.0.1`, `localhost`, and the server's network IP
   106→   106→   106→- **Fix**: Added `127.0.0.1`, `localhost`, `21.0.4.19` to `allowedDevOrigins`
   107→   107→   107→
   108→   108→   108→#### Issue #4 — Missing Profile Image 🟡
   109→   109→   109→- **Symptom**: 404 for `/default.png` (all users have `profileImg: "default.png"`)
   110→   110→   110→- **Fix**: Created `public/default.png` — teal circular avatar placeholder (200×200 PNG, 6.8KB)
   111→   111→   111→
   112→   112→   112→#### Issue #5 — Platform Proxy (port 81) Not Routing to App 📋
   113→   113→   113→- **Observation**: System Caddy on port 81 serves a Z.ai placeholder page, NOT proxying to Next.js
   114→   114→   114→- **Status**: This is platform-level behavior; the preview panel uses its own routing mechanism
   115→   115→   115→- **Impact**: agent-browser cannot verify the app (Chrome runs in isolated network namespace)

   492→   492→   492→5. 🟡 **`POST /api/auth/register` — Open Role Registration**: Any role (admin, doctor, hospital, etc.) can be self-registered. No role restriction.
