   124→### Model Queries Used
   125→- **Users_model::count_doctor_by_hospital($id)** → `SELECT COUNT(*) FROM doctors WHERE hospital_id=$id`
   126→- **Booking_model::get_hospital_appointment_count_pending($hid)** → Joins `booking, users u1, users u2, doctors d` where `d.hospital_id=$hid` and `status='Pending'`

   128→- **Doctors_model::get_by_hospital($hid)** → Raw SQL: `SELECT d.*,u.* FROM doctors as d,users as u WHERE d.user_id=u.id and hospital_id=$hid`
   129→- **Hospital_model::get_chart_data_month_wise($ids)** → 12 queries on `booking` table, `SUM(appointment_charge) as totalcollection` grouped by month, filtered by `status='Visited'` and `doctor_id IN ($ids)`

   138→## 4.2 Appointment Management

   145→
   146→### Method: `index()`
   147→- **GET param:** `status` (default: PENDING)
   148→- Iterates all hospital doctors via `doctor->get_hospital_doctors($user->id)`
   149→- For each doctor, gets their profile via `doctor->get_profile($doc->id)`, then fetches appointments by doctor profile ID and status
   150→- Merges all appointments into one array
   151→- **View:** `hospital/appointment`
   152→
   153→### Method: `show($id)`
   154→- Gets single appointment via `book->get_doctor_appointment_one($id)`
   155→- Null check redirects to `hospital/appoinment`
   156→- **View:** `hospital/appointment_show`
   157→
   158→### Method: `add()`
   159→- Fetches hospital doctors via `doctor->get_by_hospital($user->id)`
   160→- **View:** `hospital/appointment_add`
   161→
   162→### Method: `add_validate()`
   163→- **POST handler** for appointment creation
   164→- Validation rule: `booking_by_hospital`
   165→- **Flow:**
   166→  1. Looks up patient by mobile: `user->get_by_mobile($data['mobile_no'])`
   167→  2. Sets `user_id` from lookup
   168→  3. Sets `status = APPROVE` (auto-approves hospital-created appointments)
   169→  4. Gets `appointment_charge` from `config_model->get_one()->admin_charge`
   170→  5. Sets `booking_type = BY_HOSPITAL`
   171→  6. Generates appointment number via `generateBookingNumber()` (format: `APMT-{N}`)
   172→  7. Creates notification to doctor and patient
   173→  8. Sends SMS with appointment details
   174→  9. Removes `mobile_no` from booking data before insert
   175→  10. Creates booking via `book->create($data)`
   176→
   177→### Method: `generateBookingNumber()`
   178→- Gets latest booking record
   179→- Extracts number after "APMT-" prefix, increments by 1
   180→- Returns `APMT-{N}` format
   181→
   182→### Method: `extend($id)`
   183→- Only works from PENDING status
   184→- Sets status to EXTEND
   185→
   186→### Method: `approve($id)`
   187→- Works from PENDING or EXTEND status
   188→- Sets status to APPROVE
   189→
   190→### Method: `visited($id)`
   191→- Only works from APPROVE status (blocks PENDING, EXTEND, REJECTED)
   192→- Sets status to VISITED
   193→- Uses `_alertSuccessResponce` (green flash)
   194→
   195→### Method: `cancel($id)` / `reject($id)`
   196→- `cancel()`: blocks only VISITED status
   197→- `reject()`: similar but has commented-out notification code
   198→- Both set status to REJECTED ("Canceled")
   199→
   200→### Method: `charges_income()`
   201→- GET params: `fromdate`, `todate`, `doctor`
   202→- Calls `book->get_doctor_wise_charges($doctor, $fromdate, $todate)`
   203→- **View:** `hospital/income_summary`
   204→
   205→### Method: `appointment_show_detail($id)`
   206→- Similar to `show($id)` but without doctor_id filter
   207→- **View:** `hospital/appointment_show`
   208→
   209→### Method: `get_all_chat_message()`
   210→- **AJAX endpoint** (POST)
   211→- Returns JSON of all chat messages for an appointment
   212→- Calls `chat->getByAppointment($appointmentId)`
   213→
   214→### Method: `send_chat_msg()`
   215→- **AJAX endpoint** (POST)
   216→- Sends chat message: `from_id` = hospital user, `to_id` = booking's patient
   217→- Status = UNREAD
   218→- Returns JSON `{status, msg}`
