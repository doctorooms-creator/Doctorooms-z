    59→    59→## 2. Design Standards
    60→    60→
    61→    61→- **Color**: Teal primary (`teal-500/600`), Amber for warnings, Emerald for success, Violet for pending, Red for errors/canceled
    62→    62→- **Components**: shadcn/ui (New York style) + Lucide icons + Framer Motion
    63→    63→- **Data**: TanStack Query (`useQuery`/`useMutation`/`useQueryClient`) for all data fetching
    64→    64→- **Toast**: `sonner` library
    65→    65→- **Auth**: `requireRole(req, 'doctor')` for all doctor API routes
    66→    66→- **Layout**: Responsive mobile-first with breakpoints sm/md/lg/xl
    67→    67→- **Loading**: Skeleton components with `animate-pulse`
    68→    68→- **Empty states**: Icon + message pattern
    69→    69→- **Status colors**: Pending=amber, Approve=emerald, Visited=teal, Canceled=red, Finish=blue, Extend=violet
    70→    70→- **Currency**: ₹ (INR) with `toLocaleString('en-IN')`
    71→    71→- **File uploads**: Accept images via `<input type="file">` → server upload to `/public/uploads/` or cloud storage, return URL
