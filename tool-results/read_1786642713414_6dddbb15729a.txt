   894→   894→`POST /api/dashboard/receptionist/ipd-bills/[admissionId]/line-items`
   895→   895→```
   896→   896→POST: Add line item
   897→   897→Auth: requireRole(req, 'receptionist')
   898→   898→Body: { chargeItemId?, description, quantity, rate?, discount?, sourceType?, sourceId?, startDate?, endDate? }
   899→   899→Logic:
   900→   900→  1. If chargeItemId provided, fetch ChargeItem to get default rate
   901→   901→  2. Calculate: amount = quantity * rate, netAmount = amount - discount
   902→   902→  3. Create BillLineItem
   903→   903→  4. Recalculate bill totals: subtotal = SUM(netAmount), netAmount = subtotal - discount + tax + roundOff
   904→   904→  5. Update balanceDue = netAmount - totalPaid
   905→   905→  6. Return updated bill
   906→   906→Response: { success: true, bill: IpdBill (updated with new line item) }
   907→   907→```
   908→   908→
   909→   909→`PATCH /api/dashboard/receptionist/ipd-bills/[admissionId]/line-items/[lineItemId]`
   910→   910→```
   911→   911→PATCH: Update line item (change qty, rate, discount, or cancel)
   912→   912→Auth: requireRole(req, 'receptionist')
   913→   913→Body: { quantity?, rate?, discount?, status? ("Cancelled"), cancelReason? }
   914→   914→Logic:
   915→   915→  1. If status === 'Cancelled', set cancelledBy, cancelledAt
   916→   916→  2. Recalculate bill totals
   917→   917→Response: { success: true, bill: IpdBill }
   918→   918→```

   921→   921→```
   922→   922→DELETE: Remove line item
   923→   923→Auth: requireRole(req, 'receptionist')
   924→   924→Logic: Soft delete (set status='Cancelled'), recalculate totals
   925→   925→Response: { success: true, bill: IpdBill }
   926→   926→```
   927→   927→
   928→   928→**3. Auto-add Room Rent (called when bill is created and daily)**
   929→   929→`POST /api/dashboard/receptionist/ipd-bills/[admissionId]/auto-room-rent`
   930→   930→```
   931→   931→POST: Recalculate/update room rent line item
   932→   932→Auth: requireRole(req, 'receptionist')
   933→   933→Logic:
   934→   934→  1. Find or create room rent line item (sourceType='RoomRent')
   935→   935→  2. Calculate days: floor((now - admissionDate) / 86400000) — but account for bed transfers
   936→   936→  3. Rate = current Bed.dailyRate
   937→   937→  4. Update quantity=days, rate=bedRate, amount=days*rate
   938→   938→  5. Recalculate bill totals
   939→   939→Response: { success: true, bill: IpdBill }
   940→   940→```
   941→   941→
   942→   942→**4. Bill Summary (Recalculate)**
   943→   943→`POST /api/dashboard/receptionist/ipd-bills/[admissionId]/recalculate`
   944→   944→```
   945→   945→POST: Recalculate entire bill
   946→   946→Auth: requireRole(req, 'receptionist')
   947→   947→Logic:
   948→   948→  1. subtotal = SUM of all Active line items' netAmount
   949→   949→  2. discountAmount = from bill record
   950→   950→  3. taxAmount = (subtotal - discountAmount) * (taxPercent / 100)
   951→   951→  4. roundOff = Math.round(netAmount) - netAmount (where netAmount = subtotal - discount + tax)
   952→   952→  5. netAmount = Math.round(subtotal - discountAmount + taxAmount)
   953→   953→  6. balanceDue = netAmount - totalPaid
   954→   954→  7. Update bill
   955→   955→Response: { success: true, bill: IpdBill }
   956→   956→```
